# CORE GEF Execution Protocol

Every implementation Work Order must contain:

- OBJECTIVE
- LEGACY_PROVIDER PREFLIGHT
- CANONICAL BASIS
- CONTEXT BUDGET
- RISK / ASSURANCE
- SCOPE
- OUT OF SCOPE
- FILES / SEAMS TO INSPECT
- REQUIREMENTS
- ARCHITECTURE RULES
- CONSTRAINTS
- ACCEPTANCE CRITERIA
- TESTS
- EVIDENCE
- DELIVERABLES
- REVIEW FORMAT PT-BR
- STOP CONDITION

## Execution rules

Resolve Git state first. Use LEGACY_PROVIDER progressively. Execute only admitted scope. Record context expansion reasons. Preserve successful independent evidence. Repair causal failures at the smallest invalidated surface. Do not advance beyond the Work Order stop condition.
